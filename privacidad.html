Política de privacidad de Sisyphus Videos

Última actualización: 1 de octubre de 2026.

1. Descripción

Sisyphus Videos es una aplicación privada utilizada para automatizar la gestión y publicación de contenido audiovisual en YouTube.

2. Uso de las APIs de Google y YouTube

Sisyphus Videos utiliza servicios y APIs de Google, incluida la YouTube Data API, únicamente después de que el usuario autorizado conceda acceso mediante Google OAuth.

La aplicación puede utilizar los permisos concedidos para realizar operaciones necesarias para la gestión del canal autorizado, como consultar información del canal, subir vídeos, consultar el estado de vídeos y configurar su publicación.

3. Datos tratados

La aplicación puede acceder a la información estrictamente necesaria proporcionada por las APIs de Google y YouTube para realizar estas operaciones.

Sisyphus Videos no vende datos personales ni comparte los datos obtenidos mediante las APIs de Google o YouTube con terceros para fines publicitarios.

4. Almacenamiento y seguridad

Las credenciales y tokens de autenticación utilizados por la aplicación se almacenan en la infraestructura privada utilizada para ejecutar Sisyphus Videos y se emplean únicamente para las funciones autorizadas.

5. Revocación del acceso

El usuario puede revocar en cualquier momento el acceso concedido a la aplicación desde la configuración de seguridad de su cuenta de Google.

6. Eliminación de datos

El usuario puede solicitar la eliminación de los datos asociados a Sisyphus Videos contactando con: jotakin04@gmail.com.

7. Contacto

Para cualquier consulta relacionada con esta política de privacidad: jotakin04@gmail.com.
